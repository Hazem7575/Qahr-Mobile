# Mobile PacketStudio — استوديو باكتات قهر موبايل

أداة سكربتات حازم بتوريك **كل باكت** بين كلاينت Conquer Online Mobile 1.1.2.3 والسيرفر، **بالشكلين جنب بعض**:
الشكل اللي على السلك (بتاع الموبايل: رقمه واسم الـ CMsg بتاعه) والشكل اللي بيوصل لكود السيرفر بعد الترجمة (رقم السيرفر
واسم الـ Msg). وأهم حاجة فيها صفحة **التغطية**: قايمة حية بالناقص في البروتوكول مرتبة بالأهمية.

شغّله من: `publish\MobilePacketStudio.exe` (ملف واحد، مش محتاج تثبيت .NET). عربي من الأول، وزرار **EN / عربي** فوق.
بيظهر لوحده في صفحة الأدوات في QahrMobile Studio (أي `Tools\<اسم>\publish\*.exe`).

![لايف](../../GitHub/docs/mobile_tools/packetstudio/ar_Live.png)

## الصفحات

| الصفحة | بتعمل إيه |
|---|---|
| **الباكتات لايف** | كل باكت في الاتجاهين لكل شخصية: الوقت، الاتجاه، رقم واسم الموبايل، رقم واسم السيرفر، الحجم (موبايل / سيرفر)، الحالة بلون (مترجمة / زي ما هي / بتتشال / مجهولة)، والملخص بالأسماء (حاجات، خرايط، NPC، وحوش). فلتر بالشخصية والاتجاه والرقم (موبايل أو سيرفر) والاسم والنص والحالة، و«اخفي الزحمة»، وإيقاف، وتابع، وسجّل. تحت: **الشكلين جنب بعض** — حقول الموبايل (protobuf بأسماء حقول الكلاينت نفسه، أو الـ struct بالـ offsets من الـ layout ومتسمية باسم حقل السيرفر اللي بتشيله) وحقول السيرفر (من الـ ProtoContract / الـ layout بتاع السيرفر) والـ hex للاتنين. |
| **التغطية (الناقص)** | كل نوع باكت ظهر ومشكلته: **بتتشال من الكلاينت** (struct مالوش layout)، **بتتشال قبل الكلاينت**، **مالهاش handler** في السيرفر، **مفيش رد** (تقدير)، **الموبايل بيتجاهلها** (مالهاش CMsg أو مالهاش Process)، ممنوعة. مرتبة بالأولوية والتكرار. تختار سطر: كلاس المحرك وملفه الأصلي (`EngineSource\index\net_messages_full.tsv`)، عناوين Create / Process وأمر `dis.py` جاهز، حقول الـ pb، الـ handlers في السيرفر، الـ layout (الملف والسطر والتعليق)، عينة hex، والحل المقترح. «انسخ قايمة الشغل» = المشاكل كقايمة مهام. تصدير CSV / JSON. |
| **ابني وابعت** | اختار رسالة: بشكل السيرفر (830 قالب من كود السيرفر: protobuf أو binary) أو بشكل الموبايل (protobuf بأرقام حقول الكلاينت، أو struct من الـ layout). املا الحقول بالاسم ← «اعمل الباكت» ← hex تقدر تعدله. تحت بيوريك **الشكل التاني اللي هيحصل فعلًا** (التحويل بتاع السيرفر نفسه). ابعت: **للسيرفر كأنها من الكلاينت ده** أو **للكلاينت ده كأنها من السيرفر**. سجل إرسال (حمّل / ابعت تاني). «عدّل وابعت» من صفحة اللايف بيفتح أي باكت متسجلة هنا بقيمها. |
| **الجلسات والمقارنة** | سجّل جلسة (`.cocap`)، افتح أو شغّل (×1 / ×5) أي ملف جلسة أو سجل السيرفر `PacketLogs\*.log`، **قارن جلستين** (قبل وبعد تصليح: اتصلح / مشكلة جديدة / لسه)، وصدّر الباكتات CSV / JSON (بالـ hex بتاع الشكلين) أو كجلسة. |
| **المجمّع** | كل NPC و SobNpc ووحش ولاعيب وحاجة على الأرض وبوابة ظهرت، ومناطق ظهور الوحوش المستنتجة، ومقارنتها بملفات السيرفر (Npcs.txt / الوحوش / البوابات). تصدير Npcs.txt و MonsterSpawns و MapStudio JSON و CSV و JSON (في `%AppData%`، وبيرفض يكتب جوه فولدر Data). |
| **التنبيهات** | سرعة مشي / نط على خانة مقفولة / انتقال من غير SetLocation، ضرب أسرع من المسموح أو أبعد، زحمة باكتات، باكت بطول غلط، قفزات فلوس — نفس قواعد PacketStudio (كل قاعدة معاها السطر في كود السيرفر). «وريني الباكت» بيروح للباكت في اللايف. |
| **الإعدادات** | المسارات، الشخصية الافتراضية، الاتصال / التسجيل لوحده، وحالة كل حاجة (الجداول، البث، الإرسال، أخطاء ملفات الـ layout). |

كل جدول: كليك يمين «نسخ المختار / نسخ الكل» أو Ctrl+C. كل التفاصيل في مربعات نص تقدر تحدد وتنسخ منها، وزرار نسخ جنب كل hex.

## منين بتيجي الباكتات

- **لايف**: البث بتاع السيرفر (`Server\Data\packetstream.txt`: port + secret، على 127.0.0.1 بس). الـ secret بيتقري لحظة الاتصال
  ومابيظهرش ولا بيتحفظ. البث شغال من غير أي تعديل في السيرفر (`[PacketStream] listening on 127.0.0.1:17957` في watch.log).
- **ملفات**: `Server\Qahr.GameServer\bin-net10\PacketLogs\<التاريخ>.log` (السيرفر بيكتب كل باكت لما `packetlog.txt` موجود)، وملفات
  الجلسات `.cocap` اللي البرنامج بيسجلها (`%AppData%\ScriptHazem\MobilePacketStudio\sessions`).
- السيرفر بيسجل C→S **قبل** الترجمة (شكل الموبايل) و S→C **قبل** الترجمة (شكل السيرفر). البرنامج بيعمل الشكل التاني بنفسه
  **بكود السيرفر نفسه**: ملفات `Networking\Mobile\MobileLayouts*.cs` و `MobileWire.cs` متضمّنة في البرنامج كـ linked files
  (من غير تعديل)، ونفس قواعد `MobileProtocol` (mobile_ids.txt بالـ in aliases، mobile_kinds.txt، mobile_block.txt). فالنتيجة هي
  هي اللي السيرفر بيعملها، و«بتتشال» معناها إن السيرفر **دلوقتي** (بالجداول الحالية) هيرميها.
- لما تحفظ أي `Data\mobile_*.txt` أو `Data\mobile_layouts\*.txt` البرنامج بيقراهم تاني لوحده (زي السيرفر) — فتقدر تكتب layout
  وتشوف التغطية بتتحسن على طول، وتقارن جلسة قبل وبعد.

## الإرسال (وضع التطوير بس)

- **للسيرفر كأنها من الكلاينت**: AdminApi `clientpacket` (`Data\adminapi.txt`). بشكل الموبايل بتعدي على `Program.Game_Receive`
  والترجمة زي باكت حقيقية بالظبط؛ بشكل السيرفر بتروح للـ handler على طول.
- **للكلاينت كأنها من السيرفر**: الـ PacketInject (`Data\packetinject.txt`، والشخصية لازم تكون في `allow=`)، ولو مش شغال
  AdminApi `clientpacket as=send`. السيرفر بيحولها للموبايل في السكة زي أي باكت.
- لو `Data\servermode.txt` مش `mode=development` الإرسال مقفول (والسيرفر نفسه بيرفض).
- سطر أوامر للسكربتات (نفس الطريق ونفس السجل):
  `MobilePacketStudio.exe --send c2s|s2c <الشخصية> <hex> [mobile|server] [ملف النتيجة]`

## اتجرب لايف (2026-10-21)

- `--send s2c TrojanQ1 <MsgTalk 2361 نص "PacketStudio test 1"> server` → `inject: sent id 2361` وظهرت في الشات على المحاكي
  ([الصورة](../../GitHub/docs/mobile_tools/packetstudio/emulator_send_s2c.png))، والكلاينت ماوقعش (نفس الـ pid).
- `--send c2s TrojanQ1 <CMsgItem 10137 Ping متسجلة> mobile` → `fed mobile packet 10137` والسيرفر رد بـ MsgItem 2427 في نفس اللحظة.

## الفحص الذاتي

`MobilePacketStudio.exe --selftest [ملف] [--live] [--log <ملف PacketLogs>]` → `RESULT: PASS`. بيفحص: الجداول، الترجمة في
الاتجاهين على 40000 باكت حقيقية من آخر PacketLogs (من غير ولا خطأ، ونفس البايتات مرتين)، الـ decoders الاتنين، التغطية والترتيب
والتصدير، drop متعمل، تسجيل `.cocap` وإعادة تشغيله بنفس النتيجة والمقارنة، 80 دورة بناء ↔ قراءة في الـ builder، المجمّع والتنبيهات،
وإن مفيش secret بيظهر. `--live`: الاتصال بالبث 6 ثواني وقايمة الأونلاين. النتيجة الأخيرة في `publish\selftest.txt`.

صور الصفحات (عربي وإنجليزي): `GitHub\docs\mobile_tools\packetstudio\` — بتتعمل بـ `--screenshot <فولدر> [--log <ملف>]`.

## البناء

```
cd "D:\Qahr Mobile\Tools\MobilePacketStudio"
dotnet publish MobilePacketStudio.csproj -c Release      → publish\MobilePacketStudio.exe
```

- `Core\` = محرك الأداة: `PcCore\` نسخة من قلب PacketStudio بتاع الـ PC (القاموس والـ decoder والأسماء والمجمّع والتنبيهات
  والـ cocap والبث والـ inject — منسوخة، الأصل ماتلمسش)، و`ServerMobile\` (ملفات الترجمة بتاعة السيرفر linked + shims صغيرة)،
  و`Mobile\` (الجداول، الترجمة، decoder الموبايل، التغطية، المقارنة).
- `Core\protocol.json` = قاموس باكتات **سيرفر الموبايل** معمول بـ protogen بتاع PacketStudio على `Server\Qahr.GameServer`
  (492 رقم، 274 protobuf). لو السيرفر اتغير كتير:
  `dotnet ...\PacketStudio\tools\protogen\bin\Release\net10.0\protogen.dll "D:\Qahr Mobile\Server\Qahr.GameServer" Core\protocol.json`
- `Data\mobile_pbschema.tsv` = أسماء حقول الـ protobuf بتاعة الموبايل (1461 حقل في 254 كلاس) من الـ `.so`:
  `MobileTools\venv\Scripts\python.exe -I Tools\MobilePacketStudio\tools\pbschema.py MobileTools\lib\libCQ2ClientEn.so Tools\MobilePacketStudio\Data\mobile_pbschema.tsv`
- الـ handlers اللي برا `[PacketAttribute]` (MobileOnly.Handle، GuildAuctionModule.TryHandle، البوكر) بيتعرفوا من كود السيرفر وقت
  الفتح، عشان مايطلعوش «مالهاش handler» غلط.

## حدود لازم تعرفها

- «مفيش رد» تقدير: طلب ماجاش بعده أي باكت للشخصية دي (غير المشي والـ ping والـ tick وظهور اللاعيبة) خلال نص ثانية.
- البث بياخد مكان واحد من 4 أماكن عند السيرفر؛ لو السيرفر زحم، بيرمي القديم ويتعدّ في «فاقد» فوق.
- سجل السيرفر النصي بيكتب أول 96 بايت بس لو `hex=` مش `-1` في `packetlog.txt` (عندنا `-1` = الباكت كلها).
