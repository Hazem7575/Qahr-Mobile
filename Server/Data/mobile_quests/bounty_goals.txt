# QahrMobile: Chinju bounty goals the quest engine cannot judge (MobileBountyGoals.cs, re-read when saved).
# The quest's own Intention lines decide what is needed:
#   View/Find/Check/Visit [lua X,</F>TaskAssemblyGfit_Find][chk_quest id,1,slot,1]  -> talk to X (slot counter)
#   Rescue[lua X,</F>TaskAssemblyGfit_Find][chk_quest id,1,slot,N]                   -> click N different X objects
#   Pick [lua X,</F>TaskAssemblyGfit_Find][chk_item item,N]                          -> click X objects, 1 item each
# A quest is offered only when every one of its X has a "target" line below.
#
# target <LuaName> npc <uid>             an NPC that is already placed (Npcs.txt), or one of the "npc" lines
# target <LuaName> object <ObjectName>   one of the "object" groups
# npc    <uid> <mesh> <map> <x> <y> <name>                    talk NPC placed by MobileBountyGoals (also in bounty_npcs.txt)
# object <ObjectName> <look> <map> <x> <y> <radius> <count> <firstUid> [item]
#        <count> objects on walkable cells within <radius> of (x,y), uids firstUid.. ; look = the mobile npc.ini
#        NpcType (mesh = look*10). Clicking one gives 1 [item] (pick) or counts 1 rescue.
#        No object is put within 5 cells of another NPC: the mobile sends the click to that NPC instead.
