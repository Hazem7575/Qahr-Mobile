# Mobile main screen: when each function (icon) opens for a player. Read again when this file is saved (no restart).
# The server sends the bits of the opened functions in MsgAction 471 at login / map change, and again by itself within
# 2 seconds when a player's mask changes (level up, reborn, VIP, quest), so the icon appears with the client's own
# "new function" animation.
#
# Line:  <id> <server_func> <name> <conditions...>          (all conditions must pass)
#   id           function id of the client's ini\luacfg\newfuncopen.dat (the BindFuncID of the buttons)
#   server_func  the client's number for the bit (bit = server_func - 1). Do not change it: it is fixed in the client.
#   conditions   level=N        player level N or more (any higher reborn also passes)
#                reborn=R       R reborns or more; with level=: (reborn, level) >= (R, N), e.g. "reborn=1 level=80"
#                vip=N          VIP level N or more
#                quest=ID[,ID]  server quests finished (ids of Data\Questinfo.ini)
#                always         open for everybody          never   never opened by the server
#   No condition at all = open for everybody.
#
# IMPORTANT (client side): a function whose official quest is 0 ("client: lev X") is ALSO opened by the client itself
# when the player reaches that level, even if the server bit is off. The server can open it earlier, not later.
# Functions with an official quest are opened only by this file (the client does not know our quests).
# The client also checks the class itself (Awake: Trojans 12, Ninjas 32, Xiake 35, other classes 33).
#
# Settings:
#   staff_all_open = 1   GM/staff accounts get every function (for testing). 0 = staff follow the rules too.
#   log = 1              print "[Mobile] functions <name>: +Forge -Arena" in the server console when a mask changes.
staff_all_open = 0
log = 1
